# 本人成就与通知账户同步

更新：2026-10-23。范围：`/my/achievements` 的默认／Twitter 两种呈现、通知已读完成及现有账户角标。设计取舍见 [ADR-0025](./adr/0025-achievement-notification-sync.md)。

## 数据归属

`packages/frontend/src/achievements/` 按 domain、adapters、store、components 分层，顶层 `index.ts` 暴露本人页面容器和必要公共类型。domain 保存唯一目录与成就事实类型；徽章复用原资产。既有 utility 对真实存量消费者保留目录导出，后续触及这些消费者时经模块公共入口迁移，不增加新消费者。

本人成就 Store 唯一持有服务端确认的列表，两种页面壳共同消费同一业务容器。组件接收只读权威模型并通过事件提交申领／重试；锁定条目仅由目录与确认列表派生。通知、路由、旧账户快照和申领请求均不能直接构造成就或解锁时间。其他既有消费者继续使用原 `MkAchievements`，其内部查询与申领流程不变。

## 刷新与申领

`claimAchievement` 的完成结果覆盖真实申领 HTTP 请求；成功后发出所属账户的 `achievementClaimed` 信号，失败不发成功信号。Store 只据此失效并重新查询 `users/achievements`。页面仍唯一持有三分钟计时器，缓存离页清理、回访重新计时；隐藏点击通过 Store Action 提交原成就名称。

首次挂载与首次 activated 共用可见租约，只初始化一次。实际缓存回访和浏览器恢复可见重新确认；实时模式只消费既有 main 频道中的成就通知，非实时模式不为成就新建 WebSocket。本地成功信号、回访及恢复可见覆盖非实时模式的同步，不承诺其他设备的成就在当前页持续即时同步。

请求串行合并失效意图；开始请求后到达的新意图保留到下一轮，旧响应不能覆盖较新请求范围。账户身份和会话归属参与提交校验。查询失败保留最后成功列表和错误入口，下一次明确意图或用户重试再次查询，不以固定延时或无上限重试推测写入完成。

## 通知已读与角标

后端 `NotificationService.readAllNotification` 使用原子比较推进 Redis 已读水位，防并发旧请求将水位回退；持久化完成后发布既有已读事件。显式全部已读和两个通知查询端点的自动已读分支都等待此完成边界，不新增 Schema、协议版本或数据库迁移。

`packages/frontend/src/notifications/` 的动作分为确认已读和同步账户。确认已读等待原接口完成，再读取 `i`；同步账户只读取 `i`。模块只保存请求调度，不保存未读计数副本，仅将同一账户确认的 `hasUnreadNotification`、`unreadNotificationsCount` 提交至既有账户状态。

全部通知页首次打开、缓存回访、恢复可见、Twitter 通知行点击与手动全部已读提交确认动作。点击不阻塞原路由，已开始的写入离页后仍完成对账。实时未读／已读事件只触发同一账户查询，账户更新事件中的这两个字段也经同一对账入口处理。并行意图合并，迟到快照及已失去当前会话归属的响应不提交。

Sidebar、MobileBar 继续消费原账户状态。局部通知行标记仍由原通知流持有，不充当服务端已读事实。原通知流的缓存订阅、筛选和自动已读规则保持既有行为；本模块只限制自身新读意图的页面／文档可见性，不宣称改造原流式组件的后台读取规则。

## 验证

真实后端入口：`packages/frontend/test/e2e/twitter-achievements.spec.ts`、`twitter-achievement-sync.spec.ts`；服务端水位边界位于 `packages/backend/test/e2e/endpoints.ts` 的 `notification read watermark` 场景。用例使用隔离账户和真实服务，传输控制仅延迟或中断实际响应。缓存场景以实际 UI 持久化设置和相同 `/my/achievements` 裸路径建立与返回缓存。

覆盖当前页计时／隐藏点击解锁、实时与非实时缓存回访、桌面／移动角标、三个 HTTP 已读入口的即时账户读取、失败保留、在途新事实和换号迟到响应。视觉以桌面、390px、320px 的明暗成就页和通知页及默认界面作同条件配对；默认网格、徽章、目录与文案继续复核。

本次运行通过 17 项浏览器集成、1 项后端水位集成、5 项邻近单元用例；14 组视觉配对为零像素差异。类型、构建、API 生成及本轮交付检查通过，生成类型没有变化。运行证据保存在 `tmp/twitter-achievement-sync-fix-20261023/validation.json` 及其引用的最终日志和视觉比较报告。浏览器业务验收不拦截静态资源，并单独断言缓存回访只使用原文档。隔离服务准备与 readiness 属于外部启动脚本，不进入业务域和组件；私有会话夹具不公开分发。该局部回归不替代 P-19 正式视觉基线。
