# Twitter 首页时间线手动刷新

## 范围与入口

首页 `pages/timeline.vue` 的 Twitter 分支通过 `TwitterStreamingTimeline` 包装既有流式组件。支持首页原有的 home / local / social / global 与固定列表来源，筛选、来源可用性及鉴权继续使用 Misskey 原规则。独立列表页、通知及其他 UI 不接入此查询所有者。

页头刷新入口沿用原有桌面设备条件。首次加载与手动刷新期间禁用按钮；旧页或新页请求在途时仍可登记一次手动意图。界面只接收查询所有者派生的初始加载、刷新状态及操作结果，不读取分页器内部状态推断业务结果。

## 数据与刷新契约

`MkStreamingNotesTimeline` 的通用 `paginatorFactory` 只替换分页器构造依赖，endpoint / params 映射仍位于原组件。未注入时继续构造原 `Paginator`。原订阅、轮询、声音、广告及队列调用保留；共享分页器不依赖 Twitter 的结果类型。

Twitter 查询所有者持有继承分页器的唯一条目集合，不建立页面实体副本或刷新失败回滚快照。手动刷新仍经过流式组件公开的 `reloadTimeline()`，由注入的所有者执行保留内容的请求。适配器使用同一个 endpoint 与筛选参数直接读取最新窗口，不先预查再发起第二次重载。

手动意图在回顶前同步记录当前已展示集合的最大 Note ID，再通知页面调用 Shell 的 `scrollToTop()`。回顶可以释放既有前置队列，因此不能在回顶后采集比较基线。新增沿用时间线 ID 游标语义，不以条目数量、首条 DOM、整页集合差异或 Promise 完成判断。空集合与未初始化分别处理。

| 结果 | 含义 | 展示 |
| --- | --- | --- |
| `updated` | 本次成功检查确认存在比点击基线更新的帖子 | 展示最新窗口，提示更新完成 |
| `unchanged` | 本次成功检查未确认到比基线更新的帖子 | 保留已加载窗口，提示本次暂无新帖 |
| `failed` | 本次查询失败 | 保留当前内容，提示重试 |
| `cancelled` | 操作已失去活动页面或查询归属 | 不显示结果提示 |

三个可见结果提示通过共享 i18n 资源读取，简体中文补充及正式翻译接管规则见 [Fork 自有功能的简体中文文案](./fork-localization.md)。

结果只描述本次有限窗口的检查，不承诺任意设备、联邦投递或后端异步索引已全量同步，也不展示未经证明的精确新增数量。补入更早条目不算新帖；响应缺项不单独构成帖子删除事实。

有新帖时重新衔接最新窗口的向后分页，不承诺保留全部历史分页。无新帖或失败时不先清空集合，不以整屏骨架屏替换已加载内容。原删除事实及实时更新在请求期间继续有效，失败不会通过旧快照撤回这些事实。

## 时序、滚动与生命周期

查询所有者串行处理首拉、翻页和刷新，重复手动意图合并。成功提交在同一同步阶段完成队列处理、条目去重与分页能力更新，保留晚到的新帖，阻止已确认删除的条目被迟到响应重新插入。

非实时模式的发帖成功通知和轮询仍进入原 `fetchNewer` 入口。请求占用期间合并一次同查询的新页意图，空闲后消费，失败不会无意图地自动重试。手动检查期间已观察到的新页意图会在结果提示前补读；补读确认新增才提升结果，补读失败显示失败而非暂无新帖。

回顶作用于当前 Shell 的真实原生滚动宿主，沿用减少动效偏好。回顶只在开始处理手动意图时发起一次，网络完成后不再次移动页面。源、筛选或账户改变会重建所有者；缓存页失活撤销其手动意图，最终卸载释放请求和监听，旧响应不得回填新查询或产生迟到提示。

## 验证入口

`packages/frontend/test/e2e/twitter-timeline-refresh.spec.ts` 使用隔离真实后端验证无新帖、新帖队列、服务端新内容、传输失败、重复点击、翻页占用、离页取消及最新窗口分页连续性。延迟和中断只作用于传输，不替换后端业务响应。

`twitter-scroll.spec.ts` 继续覆盖 Shell 主滚动宿主、导航重选、队列回顶与原生分页。固定数据、视口和主题的 before / after / diff 用于局部视觉回归，不自动成为 P-19 的正式基线。运行结果以本次交付产物为准，用例存在不等于通过。
