# ADR-0034：私信复用共享 Shell 导航与尺度

## 状态

已采纳（2026-10-25，项目所有者同意按共享 Shell 一致性方案实施）。

本决策替代 [ADR-0033](./0033-twitter-messages-workspace.md) 中桌面私信固定使用图标侧栏的部分，以及该方案落地时采用的独立桌面列宽、页头和筛选表现。ADR-0033 原文保留为历史，不修改其记录；其路由、独立滚动、状态所有权、业务租约、权限、标读及发送约定继续有效。

## 背景

初次私信工作区从所有者提供的 X 归档补充 Nitter 缺少的聊天布局，使用全桌面图标侧栏，收件箱按 `35%`、最小 `400px`、最大 `36rem` 分配宽度，局部页头为 `64px`，标题使用 `20px` 大标题 Token，筛选使用胶囊选中态。这些参数使私信与现有 Twitter UI 的完整侧栏、主列尺度、页头和标签切换表现不一致。

现有 Shell 已有 `275px` 完整导航、`72px` 图标导航、`600px` 主列、`350px` 右栏和 `1280px` 宽桌面边界。私信不展示推荐右栏，可把主列与右栏既有空间合并为独立会话工作区，无需新增另一组权威列宽。所有者要求保留私信业务和移动交互，将上述视觉尺度统一到共享 Shell。

## 决策

1. 视口达到现有 `1280px` 宽桌面边界时，私信使用 `275px` 完整导航，工作区最大宽度由 `calc(var(--twitter-main-width) + var(--twitter-right-rail-width))` 派生；当前为 `600px + 350px = 950px`，不新增固定 `950px` 权威常量。收件箱复用 `--twitter-right-rail-width`，会话占剩余空间，内宽允许受边框占位影响。
2. `501–1279px` 紧凑桌面使用 `72px` 图标导航和最多 `600px` 单栏工作区；单栏按当前路由显示收件箱或会话。移动布局继续使用现有设备判断和可用宽度，收件箱保留底栏，会话隐藏底栏，私信页均隐藏发帖 FAB。
3. 保留实际工作区容器达到 `918px` 时分栏的既有判定。它是容器几何条件，不是新的视口断点；不把 `918px` 写入组件媒体查询，也不复制现有全站断点。
4. 收件箱与会话页头消费共享 `--twitter-header-height`（当前 `50px`），标题消费 `--twitter-font-size-title`（当前 `18px`）。空态大标题及 `96px` 圆形、`48px` 图标仍有各自展示语义，不随页头标题一并缩小。
5. 全部／私信／群聊筛选使用共享 `TwitterTabIndicator`，保持选中值、路由和请求的原有所有权。指示条仅承担几何与动效，等分命中区、ARIA、键盘焦点和筛选动作继续由原控件负责，不新增独立动画时序或业务状态。
6. 以上只调整共享 Shell 与消息展示层。不改变有界工作区、收件箱／消息独立滚动、普通页位置恢复、单一活动业务租约，以及可见且到底部附近才显式标读的条件。编辑器继续处理可视视口、safe-area、输入法组合输入及原发送键偏好。

## 未采用的方案

- 继续在全部桌面宽度使用图标侧栏：私信与相邻普通页面的导航形态和内容起点不一致。
- 为消息工作区新增固定 `950px` 常量或复制现有列宽：会形成共享尺度的第二份权威值。
- 同时保留 X 归档的 `35%`／`400px` 收件箱和 `64px` 页头：与本次共享 Shell 目标冲突；这些值仅保留在本 ADR 作为被替代方案。
- 把 `918px` 当作视口断点：实际工作区宽度还受导航、父容器和可用空间影响，视口宽度不能替代分栏条件。
- 借样式统一改写聊天 Store、权限、标读或键盘逻辑：超出本次一致性修复范围，并破坏既有业务证明。

## 验证边界

专项覆盖 `500／501px` 与 `1279／1280px` 两侧、`1440px` 宽桌面、移动窄屏、明暗主题、收件箱与会话；同时测量导航、工作区、收件箱、页头和指示条的实际几何，检查无横向溢出。共享筛选需检查选中态、快速切换、动画关闭、键盘焦点和真实筛选请求。

真实后端交互与普通 Shell 回归需在调整后执行；原有私信接入测试结果不自动证明新布局通过。独立滚动、时间线往返锚点、活动租约、移动底栏、编辑器可视视口及发送控件可达性仍是边界。固定数据的 before／after／diff 用于审阅此次一致性调整，不替代 P-19 全站视觉基线、移动真机软键盘或 Safari 核验。

当前契约见 [messages.md](../messages.md) 和 [scroll-layout.md](../scroll-layout.md)，实际结果与专项材料见 [messages-validation.md](../messages-validation.md)。
