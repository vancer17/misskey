# ADR-0029：标签指示条端点形状统一

## 状态

已采纳（2026-10-23，项目所有者要求按排查结论修复）。

仅补充 ADR-0027 中的圆角决策；标签布局、内缩、颜色、动效和业务交互继续沿用现行契约。

## 背景

ADR-0021 与 ADR-0027 保留了各页既有圆角。频道入口原指示条使用四角全圆，其余四排仅圆上角；迁移共享组件时，频道入口以局部参数保留了全圆角。人工核查发现，在相同 `4px` 高度下，频道入口显示半圆端点，而通知、资料等页面显示上圆下直的端点，跨页形状不一致。

逐页与旧图进行零差异比较会保留该差异；仅验证落点、宽度和动画也不能证明跨页端点一致。

## 决策

1. 五排共享指示条统一为 `var(--twitter-radius-pill) var(--twitter-radius-pill) 0 0`，仅上角圆、下角直。
2. 删除频道入口的局部圆角覆盖，并移除共享组件已无消费者的圆角覆盖参数；局部参数只控制现有内缩。
3. 全局 `--twitter-radius-pill` 继续服务原组件；不通过调整该 Token 改变全站按钮或头像。
4. 真实页面回归同时验证五排指示条四角和高度；截图 diff 检查频道变化限于端点，标签和指示条的落点、宽度保持一致。

## 当前契约与验证

现行实现见 [横向标签指示条转场](../tab-indicator-motion.md)。验证结果随交付报告记录，本 ADR 不预先声明测试或平台通过。
